# Adda Arena 🎭

বন্ধুদের নিয়ে খেলা আর আড্ডার অ্যাপ — **সম্পূর্ণ অফলাইন, কোনো সার্ভার নেই, সব ফ্রি**।

WePlay-এর মতো পার্টি গেমের ধারণা থেকে বানানো, কিন্তু সব গেম, লেখা আর ডিজাইন **নিজের বানানো (original)** — WePlay-এর কোনো কোড, ছবি বা কনটেন্ট কপি করা হয়নি।

## বানানো কীভাবে

অ্যাপটা একটা ওয়েব অ্যাপ (HTML/CSS/JS, কোনো ফ্রেমওয়ার্ক নেই) — Android-এ WebView দিয়ে মোড়া।
তাই একই কোড ব্রাউজারে আর APK-তে চলে, বিল্ড ছাড়াই।

```
adda-arena/
├── web/              # আসল অ্যাপ (index.html, css, js, games)
├── android/          # WebView wrapper (Java) + manifest + icons
├── build.sh          # Gradle ছাড়া APK বিল্ড (aapt2 + d8 + apksigner)
├── gen_icons.py      # আইকন জেনারেটর (Pillow)
└── sdk/android.jar   # লোকাল বিল্ডের জন্য (git-এ নেই)
```

### লোকাল বিল্ড

```bash
sh build.sh            # → adda-arena.apk
```

`aapt2`, `d8`, `apksigner`, `javac`, `keytool`, `zip` PATH-এ থাকতে হবে।
`SDK=/path/to/android.jar sh build.sh` দিয়ে SDK বদলানো যায়।

### GitHub Actions

প্রতি push-এ APK বিল্ড হয়ে artifact হিসেবে যায়; `v*` ট্যাগ দিলে Release-এ APK যুক্ত হয়।

### ব্রাউজারে চালাতে

```bash
cd web && python3 -m http.server 8080
```
